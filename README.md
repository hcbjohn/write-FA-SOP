# write-FA-SOP

把检验标准（国标 PDF）编写成检验操作规程（SOP）的 AI 技能，支持一键导出 Word。

**它解决什么问题：** 你手头有一份国标 PDF（如 GB 5009.44-2016《食品中氯化物的测定》），想把它变成一份自己化验室能直接用的检验操作规程？这个技能就是干这个的——你把 PDF 发给 AI 助手，它按你公司的格式要求，自动帮你写好一份规范的操作规程文件。

**给小白看的重点：** 你不需要懂编程、不需要装 Python、不需要碰命令行。所有技术活都由 AI 助手在后台自动完成。

## 功能

-   直接把国标 PDF 变成检验操作规程（Markdown），无需自己排版
-   **绕过国标乱码**：很多从网上下载的国标 PDF 打开全是乱码，本技能会自动对每一页做 OCR 识别，把乱码全部恢复成正常文字，再继续生成规程，流程不中断
-   直接调用内置模板 `templates/SOP_TEMPLATE.md` 生成规程，无需每次提供模板；模板可定制，直接编辑该文件即可
-   每次执行时先读取标准文件中的全部检验方法及名称，由用户选择本次要编写的检验方法
-   支持专业背景文件：填写一次行业、食品类型、检验项目，之后自动按你的行业裁剪无关内容（如你做调味品，自动去掉国标里乳制品相关的步骤）并优化规程
-   公式转 LaTeX、复杂表格转 HTML 表格、检验图谱转 BASE64，保持单文件，但会影响markdown性能
-   规范 Markdown：段落间空行、标题层级清晰、编号连续
-   交付格式可选：每次交付前询问，导出 Markdown 文件，或 Markdown 文件 + Word 文件（.docx）

## 小白傻瓜教程

以下步骤适用于安装了任意 AI 助手软件（千问、千问办公、豆包办公、qorder 等）的用户。全程不需要写代码、不需要配置任何环境。

### 第一步：下载技能包

1.  点击下面的链接，下载技能包压缩文件：
    
    > 下载链接（占位，发布后请替换为实际地址）： [https://github.com/qwen-work-assistant/write-FA-SOP/raw/main/write-FA-SOP.zip](https://github.com/qwen-work-assistant/write-FA-SOP/raw/main/write-FA-SOP.zip)
    
2.  把下载好的 `write-FA-SOP.zip` 解压，得到一个名为 `write-FA-SOP` 的文件夹。
    
3.  把这个文件夹放在电脑上一个好找、固定的位置，例如 `D:\skills\write-FA-SOP` 或 `C:\Users\你的用户名\Documents\skills\write-FA-SOP`。**记住这个路径**，后面要用。
    

### 第二步：告诉 AI 助手技能在哪

打开 AI 助手软件，新建一个对话，把技能文件夹的路径发给它，例如直接说：

> 请加载并使用这个技能：D:\\skills\\write-FA-SOP
> 
> 这个技能是用来把国标 PDF 写成检验操作规程的。

AI 助手会自动读取技能包并进入待命状态。如果软件有"导入技能 / 技能市场"功能，也可以直接导入技能文件夹或里面的 `SKILL.md` 文件，效果一样。

### 第三步：把国标 PDF 发给它

把你要写规程的国标 PDF（例如《GB 5009.44-2016 食品安全国家标准 食品中氯化物的测定》.pdf）以文件方式发送给 AI 助手，然后用一句话说明需求，例如：

> 请用这个技能，把这份国标的第一法写成检验操作规程。

### 第四步：跟着提示做几个简单选择

AI 助手会自动完成识别、整理、排版，中间只会问你几件"点一下就能回答"的事：

1.  **选择检验方法**：如果国标里有"第一法、第二法、第三法……"，它会列出来让你选（默认推荐第一法）；
2.  **（首次使用时）专业背景**：它会问你公司是做什么食品的（可选）——如果不想填，直接选"忽略并继续"即可；
3.  **选择交付格式**：只要 Markdown 文件，还是 Markdown + Word 都要？按你需要选一个。

### 第五步：收文件

完成后，AI 助手会把成品的检验操作规程文件发给你（Markdown 或 Word），直接保存到电脑里就能用。

以后每次想写新规程，重复第三步～第五步即可，不需要再重新教它。

## 模板定制（可选，进阶用户）

模板文件为 `templates/SOP_TEMPLATE.md`，其中以 `【】` 标注的是生成时由技能按国标内容填充的占位项。模板当前预设：

-   范围用一句话表述：本文件适用于采用【标准号】【第几法】（【方法名称】）测定【食品类别】中【检验项目】
-   数据处理章不设 5.1/5.2/5.3 小标题，结果计算、精密度、定量限等内容直接列于章下

常见定制项：

-   增加/删除章节（如加"文件信息头" YAML 栏、加"更改记录"章）
-   调整章节顺序或编号层级
-   修改段落空行、标题级别等 Markdown 排版约定

## 专业背景定制（可选）

背景文件位于 `templates/`，存在两个状态：

-   `PROFILE_TEMPLATE.md`——首次录入模板：初始即此文件名，表示尚未录入基础信息。填写行业、食品类型、检验项目、其他约束四项后，文件重命名为 `PROFILE.md`。
-   `PROFILE.md`——已录入背景：录入完成后由 PROFILE\_TEMPLATE.md 改名而来，之后的运行直接读取它；可随时编辑录入或修改，改动即时生效。

**首次运行判定**：技能仅首次运行检查文件名——文件名含 `PROFILE_TEMPLATE` 即视为未录入，此时只有两种选择：忽略并继续运行（本次按国标全量生成，不裁剪，下次仍会提示），或终止任务、引导用户录入背景后改名 `PROFILE.md`。

技能自动按 `PROFILE.md` 中的背景信息：

-   **裁剪无关试样步骤**：按所填食品类型，删除国标方法中无关食品类别的试样处理步骤（如背景为调味品时自动去除乳制品相关步骤），保留相关步骤并重新连续编号。
-   **优化整个规程**：按行业与食品类型合并精简"范围"的适用范围表述，突出本行业食品类别；国标明列的除外条款原文保留。
-   **不变内容**：试剂、仪器设备、结果计算、精密度等通用内容保持国标原文，不发散、不补数值。
-   未录入且选择忽略时，技能按国标全量生成，不做裁剪。

## 依赖与零配置保证

**对最终用户零配置**：使用本技能的客户只需安装/打开 AI 助手软件（如千问、千问办公、豆包办公等），无需具备任何编程与系统配置能力。

-   乱码 OCR 路径由 AI 助手在本地自动执行 `scripts/ocr_pdf.py`：脚本运行时会自动检测并自动安装所需依赖（PyMuPDF）；如自动安装失败（离线/受限环境），AI 助手自动降级使用内置文档解析与图像识别能力完成同样任务，流程不中断，用户无感知。
-   导出 Word（.docx）由 AI 助手自动调用 Word 转换能力完成，用户无感。
-   其余流程由 AI 助手内置能力完成（文档解析、图像理解、Markdown 生成）。
